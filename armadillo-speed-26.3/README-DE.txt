ARMADILLO SPEED - Fabric Minecraft 26.3

Diese Mod beschleunigt NUR Guerteltiere:
- Babys wachsen in ca. 30 Sekunden (600 Spielticks) heran.
- Paarungspause ca. 30 Sekunden (600 Spielticks).
- Andere Tiere, Villager, Pflanzen und Redstone bleiben unveraendert.
- Nur serverseitig installieren. Keine Fabric API benoetigt.

WICHTIG: Dies ist der QUELLCODE, noch keine fertige .jar-Datei.
Der Code wurde in dieser Umgebung nicht kompiliert oder im Spiel getestet.

Bauen:
1. Java JDK 25 und Gradle 9.6 installieren.
2. Im Projektordner 'gradle build' ausfuehren.
3. Die fertige .jar aus build/libs/ (NICHT die -sources.jar)
   in den mods-Ordner des Fabric-26.3-Servers legen.
4. Server nach einem Welt-Backup neu starten.

Bei einem Buildfehler die genaue Fehlermeldung senden.
